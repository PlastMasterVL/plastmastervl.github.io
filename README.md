
и замените на нужный адрес.

## Публикация на Vercel (без установки чего-либо на компьютер)

1. Загрузите эту папку на GitHub (можно через github.com — кнопка "Add file" → "Upload files", перетащить все файлы)
2. Зайдите на vercel.com, войдите через GitHub
3. "Add New Project" → выберите загруженный репозиторий
4. Framework Preset определится сам как **Vite** — ничего менять не нужно
5. Нажмите **Deploy**

Через 1–2 минуты сайт будет доступен по ссылке вида `https://ваш-проект.vercel.app`.

## Важное ограничение первой версии

- Товары, новости редактируются через админ-панель на сайте; акции — напрямую в Supabase → Table Editor
- Фото при добавлении товара через админку показываются только в вашем браузере, пока страница открыта (демо-режим загрузки файлов). Чтобы фото были видны всем и постоянно, нужно подключить Supabase Storage — можно донастроить отдельно
